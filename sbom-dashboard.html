What this cannot tell you

  • Lookup-ready means the prototype recognizes the package type and version. The coverage script queries no database.
  • No linked match is not proof a component is safe. Matches are joined by exact package URL, so a formatting difference could hide one.
  • Components missing from the SBOM are invisible here.
  • This is one snapshot: one tool version, one vulnerability database date, one copy of the source.
  • It is a visibility aid, not a security assessment or a certification.
